# R7 repository context: Hunter Newton 2017 exercises

This repository is a collection of Road to Hire-era HTML, CSS, and JavaScript learning exercises, rather than one application. `DailyChallenges/DailyChallenges/` contains week-based pages, including a multi-page arepas recipe under `Week 6/Tuesday July 25th, 2017 Daily Challenge/` and a comment-form exercise under `Week8/Thursday/`. `DailyChallenges/JavaScriptChallenges/` and `WeeklyChallenges/` hold exercise text and related files. `examples/html-basic/` is a separate biography-style site with `index.html` and other pages.

There is no repository-wide build or test command in the checked tree. Open an exercise's own `index.html` or `form.html` in a browser. For recent source-checked history, see [July 2017 changes](changes/2017-07.md) and [August 2017 changes](changes/2017-08.md). See [implementation choices](decisions.md) for the directory pattern.
